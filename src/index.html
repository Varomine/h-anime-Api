GET /api/filters
Fetch the list of available genres (categories), release years, and airing statuses.
Query Parameters
None required.
Example Response
{ "genres": [ "Hentai เฮ็นไต", "Big Breasts หน้าอกใหญ่" ], "years": [ "2026", "2025" ], "status": [ "จบแล้ว", "ยังไม่จบ" ], "sort": [ "latest", "title" ] }
GET /api/filter
Filter series by genres, release years, airing status, and sort options (supports pagination).
Query Parameters
Parameter Type Required Description
genres string / array No Filter by genre(s). Can be multiple parameters or a single comma-separated list.
years string / array No Filter by release year(s). Can be multiple parameters or comma-separated.
status string / array No Filter by airing status ('จบแล้ว' or 'ยังไม่จบ').
sort string No (default: latest) Sorting order. Supported values: 'latest' (newest releases first), 'title' (alphabetical order A-Z).
page integer No (default: 1) The page number offset to load.
Example Response
{ "currentPage": 1, "totalPages": 12, "results": [ { "title": "Ookii Onnanoko wa Suki desu ka?", "url": "https://www.alpha-hen.com/ookii-onnanoko-wa-suki-desu-ka/", "thumbnail": "https://www.alpha-hen.com/wp-content/uploads/2026/04/325424.jpg", "score": "6.45", "tag": "Hentai", "episodes": "8/12", "status": "ยังไม่จบ", "language": "ซับไทย" } ] }
